# Rules Summary — Nebius x NVIDIA Global AI Hackathon

Verified Oct 11, 2026 by reading the official rules, resources, and dates pages in full.
**The official rules govern:** https://nebiusglobalaihackathon.devpost.com/rules
This file is a working summary, not a copy of the rules.

## Key dates (all Pacific)

- Submission period: Aug 26, 2026, 9:00 AM – **Oct 30, 2026, 10:00 AM**
- Judging: Dec 1, 2026, 9:00 AM – Dec 15, 2026, 12:00 PM
- Winners: on or around Jan 11, 2027, 12:00 PM

## Eligibility

- Individuals at least the age of majority where they reside; teams of eligible individuals; organizations existing at time of entry.
- Teams/organizations appoint one authorized representative to submit.
- No maximum team size is stated in the rules.
- Excluded: residents of / organizations domiciled in places where US or local law prohibits participation or prizes (the rules list includes Brazil, Quebec, Russia, Crimea, Cuba, Iran, North Korea, and comprehensively OFAC-sanctioned countries); sponsor/administrator employees and households; anyone involved in producing the hackathon, judges, and their employers/affiliates; conflicts of interest.
- A US resident in California is not in any excluded category listed.

## What to build

A working software application that:

- Runs on **Nebius Token Factory OR Nebius AI Cloud**, and
- Uses **at least one NVIDIA open-source model**, and
- Fits one track:

1. **Coding and Agentic Engineering** — coding agents / developer tools
2. **Best Apps and Agents** — a usable app or agent / self-running workflow
3. **Personal AI** — always-on private assistant, persistent memory, reusable skills, user-controlled data
4. **Physical AI** — embodied/edge agents (robotics, IoT, on-device)

## What to submit

- Working demo URL (not required for Physical AI)
- Text description of what was created, why, and how it works
- Track selection
- Public code repository (GitHub, GitLab, or Bitbucket) with all source needed to run it, an open-source license file visible at the top of the repo page, and a README with setup/run instructions highlighting the NVIDIA model use and Token Factory use
- Demo video: 3 minutes or less, public on YouTube (Physical AI: at least 1 minute of hardware operating, or key modules in action if no hardware)
- Feedback section on Token Factory, AI Cloud, and NVIDIA tools/models used
- Pre-existing projects: allowed only if significantly updated during the submission period, with a written explanation of the updates
- All materials in English (or with English translation)
- Multiple submissions allowed if each is unique and substantially different
- The project must be available free of charge, without restriction, for judging until the judging period ends

## Prizes

- Grand Prize: $20,000 (1 winner)
- 2nd Place: $10,000 (1 winner)
- 3rd Place: $6,000 (1 winner)
- Track winners (1 per track): 1 NVIDIA Jetson Orin Nano each
- Best Use of Tavily: $3,000 (1 winner) — requires a functional, runtime Tavily API call
- City Winner Awards: $500 × 20 (San Francisco and Los Angeles are among the listed cities; attending an in-person event is not required)
- Most Valuable Feedback: $100 + NVIDIA swag × 10
- Stacking: each project is eligible for one Overall Award OR one Track Award, and one Bonus Award

## Judging

- Stage One (pass/fail): genuine fit to theme/track and genuine use of the required stack — not a superficial rebrand.
- Stage Two (four equally weighted criteria):
  1. **Technological Implementation** — build quality and effective use of Nebius + NVIDIA models
  2. **Design** — a complete, coherent product experience, not just a proof of concept
  3. **Potential Impact** — a credible, specific case for a real problem for a real audience, addressed by what is demonstrated
  4. **Quality of the Idea** — creative, non-obvious use of the stack, genuine understanding of the problem space
- Judges are **not required to test** the project and may judge on description, images, and video alone.

## Credits (from the official Resources page)

- $25 Token Factory credits via the linked form (activation code on the Resources page)
- Another $25 Token Factory credits via the free Nebius Builders Program (also Tavily and Nebius Academy credits, office hours)
- No base AI Cloud (GPU) credits are documented. AI Cloud signup charges a real $25 to a card — this project avoids AI Cloud.
